# Showcase

Have you ever wanted to send a friend a clean picture of a card you made in Balatro, but it always meant badly screenshotting it in the collection? Ever wondered if the JokerForge preview for cards could be reimagined for ease of use elsewhere?

Well, this is the mod for you!

Showcase is an extremely lightweight mod with one function: screenshotting objects for external use. Accessible through the escape menu in the main menu, you input a card's key, set whether or not info_queues or card art should be included, set a delay (useful for if a mod has a rotating badge), and hit the big Showcase button! The screenshot of the description will be stored alongside your Mods folder in a folder titled "showcase".

**Showcase has no dependencies, and functions without Steamodded.**

This was initially meant as something to use personally rather than to share, but it ended up being a fun project to work on for a day or two and learn a bit more on description UI, LOVE, and simply making a mod that doesn't use anything from SMODS. It'll likely receive minimal updates other than maybe bug fixes given how small it is.

Thanks to Foo54 for indirectly helping me realize that this kind of thing didn't exist already.
